GitHub-repo + Pages (admin Control Center)
==========================================

1. Repo (als die nog niet bestaat), als hgj-isw:

   gh repo create hgj-isw/kavel-veiling-admin --public --source=. --remote=origin --push

2. Bouwen (met live API):

   npm install
   VITE_API_URL=https://kavel-veiling-api.hgj-isw.workers.dev npm run build:pages
   # maakt dist/index.html én dist/404.html (SPA-fallback voor /login e.d.)
   # Zonder VITE_API_URL blijft de UI op lokale mock/localStorage.

3. Pages-branch:

   # inhoud van dist/ naar branch gh-pages
   npx --yes gh-pages -d dist

4. Settings → Pages → Deploy from a branch → gh-pages → / (root) → Save

5. Open: https://hgj-isw.github.io/kavel-veiling-admin/

   Deep-links zoals /login geven HTTP 404 van GitHub Pages, maar 404.html
   is een kopie van index.html zodat de SPA toch laadt.

Login live: hgj@isw.info · toegangscode (ACCESS_CODE)
Login mock (geen VITE_API_URL): hgj@isw.info · test-PIN 1234

Onzinbiedingen: handmatig, één voor één, na window.confirm → DELETE /api/admin/biedingen/:id

Backup (Instellingen): versleutelde .json.enc download/import
  - GET /api/admin/export?format=json + Bearer → AES-256-GCM client-side
  - Geen raw CSV/JSON-knoppen; geen R2
